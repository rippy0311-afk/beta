# Beta

「全てが中途半端な世界で生まれた男の子が、少しずつ世界を完璧にしていく」横スクロール・ピクセルRPGの基盤です。

## 現在のBeta版：第1章「はじまりの足場島」

企画書全20章のうち、最初の章を遊べる縦切り出しとして実装しています。

- 主人公レン：移動、ジャンプ、近距離攻撃
- 相棒ピース：追従・修復のヒント
- 通常敵ハーフスライム：倒すとCOMPLETEゲージが増加
- 修復ポイント：`E`で仮設足場を完成させる
- 完成のかけら：収集で世界修復率とCOMPLETEゲージが上昇
- COMPLETEゲージ：敵の撃破／修復／収集で増加
- 目標：かけらと修復を完了し、島の終点へ到達

### スプリント航路

第1章は全13ステージを予定しており、現在の約9,000ワールド幅の長距離コースはそのうちの `STAGE 1 / 13` です。走行を止めない連続ジャンプのリズムを採用しつつ、青い風標・完成のかけら・修復灯を次の着地点のガイドとして配置しています。特定のマリオメーカーコースの配置や素材を複製せず、アルケアの浮島・未完成の仮設足場・修復を軸にしたオリジナルコースです。

第2章以降、ボス、武器、特殊能力、拠点成長、20章のマップギミックを拡張予定です。

広い背景は元の浮島と滝の景色を保ち、遠くの城だけを工事中にします。プレイヤーが乗る浮岩は、薄い草地の下に石材ブロック・木製の支え・露出した基礎・補強材が見える未完成の足場として描きます。

## 遊び方

- `← →` または `A / D`：移動
- `Space`：ジャンプ
- `Z`：近距離攻撃（敵を倒せます）
- `E`：近くの修復ポイントを起動
- 青い完成の欠片を5つ集め、右端の門へ向かいます。

## 機能の追加・削除

`systems/gameplay-options.js` の `FEATURES` だけを変更してください。各フラグは、完成済みのゲームループを損なわない表示・補助に限っています。

現在の機能：タイトル、HUD、会話、収集、世界修復、チェックポイント、モバイル操作、パーティクル、セーブ枠、敵の巡回・接触リスポーン、主人公の歩行アニメーション。

敵と歩行は基本システムのため、`FEATURES` には置いていません。

## ローカル保存

- ポーズメニュー（初期キーは `Esc`）の「セーブ」で3スロットに保存・読込・削除できます。上書き、読込、削除には確認があります。起動時はスロット一覧を復元し、冒険は選んだスロットから手動で読み込みます。
- 保存対象は位置、向き、経過時間、COMPLETEゲージ、チェックポイント、欠片、修復、敵の生存状態、能力フラグです。読込後はポーズ状態になり、一時的な移動・攻撃・開発用の浮遊状態は解除されます。開発用の物理調整値は保存しません。
- 音量とキー割り当ては変更時に自動保存し、起動時に復元します。「初期キーへ戻す」はキーのみ、「音量とキーを初期設定へ戻す」は両方をリセットします。音響機能自体は引き続き未実装です。
- `FEATURES.saveData` はセーブUIと保存・読込処理、`FEATURES.persistentSettings` は設定の永続化を制御します。`false` の機能は保存領域にアクセスせず、既存データも削除しません。設定UIは永続化OFFでも起動中は利用できます。能力の読込は `abilitySystem` に従います。
- `localStorage` のキーは `beta.save.v1.1` ～ `beta.save.v1.3` と `beta.settings.v1`、データ形式の `version` は `1` です。不正なデータ・未対応バージョンは適用せず、設定は初期値、スロットは読込不可として表示します。削除や上書きで復旧できます。保存禁止・容量不足時は画面に通知し、ゲームは続けられます。他のアプリの保存データには触れません。
- 保存先は同じブラウザー・同じオリジン（プロトコル、ホスト、ポート）です。安定した利用には固定のローカルHTTPサーバーで開いてください。ブラウザーデータを削除すると保存も消えます。「最初からやり直す」は保存スロットを削除しません。
